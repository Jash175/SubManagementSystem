# Brightloop Documentation

This directory contains architectural specifications, implementation plans, and domain design notes for the Brightloop Subscription Management System (Odoo × Lucknow Hackathon).

The primary specifications and reference documents are preserved in [`brightloop_handoff/`](../brightloop_handoff/):

- [`01_PRODUCT_REQUIREMENTS.md`](../brightloop_handoff/01_PRODUCT_REQUIREMENTS.md) — Complete requirement inventory, user roles, business rules, and acceptance criteria.
- [`02_ARCHITECTURE.md`](../brightloop_handoff/02_ARCHITECTURE.md) — System architecture, module boundaries, security rules, and data flows.
- [`03_DATABASE_DESIGN.md`](../brightloop_handoff/03_DATABASE_DESIGN.md) — Entity relationships, database constraints, indexes, and lifecycle design.
- [`04_TECH_STACK.md`](../brightloop_handoff/04_TECH_STACK.md) — Selected technology stack, libraries, and environment variables.
- [`05_API_CONTRACT.md`](../brightloop_handoff/05_API_CONTRACT.md) — REST API endpoints and payload schemas.
- [`06_IMPLEMENTATION_PLAN.md`](../brightloop_handoff/06_IMPLEMENTATION_PLAN.md) — Hackathon phased implementation roadmap.
- [`07_TEST_AND_DEMO_PLAN.md`](../brightloop_handoff/07_TEST_AND_DEMO_PLAN.md) — Acceptance testing criteria and demo script.
- [`08_BILLING_ALGORITHM.md`](../brightloop_handoff/08_BILLING_ALGORITHM.md) — Recurring billing, discounting, tax calculations, and calendar edge-cases.
- [`09_PROJECT_STRUCTURE.md`](../brightloop_handoff/09_PROJECT_STRUCTURE.md) — Recommended codebase organization and ownership boundaries.
- [`10_TRACEABILITY_MATRIX.md`](../brightloop_handoff/10_TRACEABILITY_MATRIX.md) — Mapping from PDF requirements to database, API, and UI components.
- [`sql/001_initial_schema.sql`](../brightloop_handoff/sql/001_initial_schema.sql) — PostgreSQL initial schema baseline.
